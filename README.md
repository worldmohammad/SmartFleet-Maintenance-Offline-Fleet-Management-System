# 🚛 SmartFleet Maintenance — Offline Fleet Management System

**100% Client-Side. Zero Server. Absolute Privacy.**

A comprehensive offline fleet preventive maintenance system. Track vehicles, schedule services, log fuel consumption, and manage documents—all without an internet connection.

## ✨ Features

- **🚗 Vehicle Management:** Add vehicles with plate, type, model, color, odometer
- **🔧 Maintenance Tracking:** Log services with cost, date, and next due date
- **⛽ Fuel Logs:** Track fuel consumption, cost, and type per vehicle
- **📋 Service History:** View all past maintenance and fuel records
- **⚠️ Smart Alerts:** Upcoming/overdue services highlighted in sidebar
- **📊 Charts:** Monthly costs, fuel consumption, cost distribution (Pro)
- **💾 Backup/Restore:** JSON export/import (Pro)
- **📥 CSV Export:** Download vehicle data (Pro)
- **🔒 100% Offline:** All data in IndexedDB
